## 执行决定与兼容性

- 在已保存基线 `c93a79c` 的现有工作目录继续，工作单元使用不同文件。风险是同时修改同一文件时需重新合并；本次按文件分工完成。
- 开发使用 gauge88-csv；公共实现使用 factory 配置提交，再以单独配置提交形成新分支。风险是切换后复用旧构建；Gradle 已改为从当前源码生成网页，APK 内配置和资源也已验证。
- 原生后台同样计算并保留完整估算和 CSV 来源。风险是增加维护成本；两端共享确定性 CSV 用例约束算法。
- 实时电量使用 `X-Gauge-Age` 的相对采样年龄，CSV 仅在设备时间域检查新鲜度。没有相对采样年龄的旧接口显示不可用，避免设备与手机时钟不同造成误判；当前设备样例接口提供该响应头。
- 最终修复中的去重比较采用实际序列化样本的充电状态，保留原分钟归档频率。风险是比较语义不一致造成额外历史点；回归检查一分钟内重复轮询只有一个点、到下一分钟新增点。

构建日志保留现有 `android.nonTransitiveRClass` 实验设置提示、旧 SDK 工具映射新元数据命名空间的提示、已有弃用 API 提示。两种配置构建均成功。最低 Android API 23 保持原设置。
