Spec: docs/superpowers/specs/2026-11-17-apk-only.md

## Global constraints

- Remove all EXE and LAN interoperability functionality; Android local acquisition/history continues.
- Preserve both battery strategies and identical branch source; only profile JSON differs.
- Keep APK H5 generation/development tooling and the Android stock localhost proxy.
- Commands use tty:true, subprocesses windowsHide:true; preserve unrelated untracked files.
- Workers edit disjoint files; root owns commits, branch references, packaging/docs and final validation.
